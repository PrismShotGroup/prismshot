01
Before you start · 评审边界

请判断体验，
暂时忽略占位内容。

这一轮请看
  • 首页呈现居中信息、水晶画框与背景能否形成完整的第一印象？
  • 信息层级是否一眼知道社团是谁、在做什么？
  • 视觉一致从首页进入内页后，气质是否连贯？
  • 使用体验导航、展开、大图和手机布局是否顺手？
这一轮先不看
  • 照片内容目前使用 Unsplash 占位图。
  • 活动资料日期、人物、赛程与文案均为示意。
  • 社交账号外链和二维码尚未替换为社团资料。
  • 后台能力投稿、登录、数据管理不在本轮范围。
NOTE

这是可公开访问的静态链接。 已设置不让搜索引擎收录，但它不是密码保护；请不要在页面或反馈中放入隐私资料。
